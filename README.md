# lark-base-unso-forms

Lark Base（多維表格）の拡張機能です。運行のレコードから **運送引受書（別記１）** と **運行指示書（別記２）** を A4 で作り、まとめて印刷・PDF保存できます。

- 選んだレコードを1件1ページで並べ、ブラウザーの印刷機能で一括印刷・PDF保存します
- 処理はすべてブラウザー内で行い、データを外部に送りません（サーバー不要）
- 事業者名・フィールドの割り当て・運賃の計算方法などは、設定画面から Base ごとに保存します。そのため、別のワークスペースや事業者でも同じ URL で使えます

## 使い方（利用者向け）

1. Base 右上の「拡張機能」→「カスタム」→「新しい拡張機能を追加」で、公開 URL（`https://<アカウント>.github.io/lark-base-unso-forms/`）を登録します（メニューの表記は Lark のバージョンによって異なります）。登録には Base の編集権限か管理権限が必要です
2. 初回は「設定」タブで次の内容を入れ、「設定を保存」を押します
   - 対象テーブルとフィールドの割り当て（「名前から自動割り当て」も使えます）
   - 運賃（フィールドの値を使うか、所要時間から計算するか）
   - 申込方法、固定で印字する内容（事業者名・運行管理者・運送引受者など）
   - 日付（作成年月日・指示年月日・確認年月日を、印刷日・運行日・空欄のどれにするか）
3. 「印刷」タブで対象（チェックした行／表示中のビューの全件／一覧から選択）と書類を選び、「読み込んでプレビュー」を押します
4. 内容と警告を確認し、「印刷・PDF保存」を押します。PDFで保存する場合は、印刷画面の送信先で「PDFに保存」を選びます。用紙は A4、余白は「なし」、倍率は 100% にしてください

※ Base の外（通常のブラウザー）で URL を開くと、架空のサンプルデータで動くデモモードになります。

## 印字のルール

| 項目 | 内容 |
|---|---|
| 地点 | 「住所」と「場所名」のフィールドを空白でつないで印字。長い住所は文字を小さくして1行に収めます |
| 運行の開始/終了 | 専用のフィールドを割り当てなければ、乗車/降車と同じ値を印字します |
| 日時 | 令和・月・日・曜日・時・分（日本時間）。令和より前の日付は年を空欄にし、警告を出します |
| 運賃（時間制） | 基本時間までは基本料金、超過分は加算単位ごとに加算料金（端数切り上げ）。0分以下は0円 |
| 合計 | 運賃＋料金 |
| 運送契約の相手方 | 既定では「運送の申込者」と同じ内容 |
| 運転者確認（印） | 設定で選んだ場合だけ運転者名を印字 |

## 開発

```bash
npm install
npm run dev      # http://localhost:5173 をカスタム拡張機能として登録すると Base 上で確認できます
npm test         # 運賃・和暦などのロジックのテスト
npm run build    # dist/ に出力
```

| ファイル | 役割 |
|---|---|
| `src/logic.js` | 運賃計算・和暦・1件分の表示データの組み立て（SDK に依存しない） |
| `src/forms.js` / `src/forms.css` | 別記１・別記２の A4 レイアウト（寸法は mm 指定） |
| `src/settings.js` | 設定の項目定義・既定値・フィールドの自動割り当て |
| `src/lark.js` | Lark Base JS SDK（`@lark-base-open/js-sdk`）との接続、設定の保存 |
| `src/main.js` | 画面の制御 |

### 公開（GitHub Pages）

1. このリポジトリを GitHub に push します
2. リポジトリの Settings → Pages → Source を「GitHub Actions」にします
3. `main` に push するたびに、テスト → ビルド → 公開が自動で行われます

Base は拡張機能の画面をキャッシュするため、更新後はパネルを開き直してください。

## 注意

- 様式は別記１・別記２の書式を元に HTML で再現したものです。使う前に、各事業者の運用や監査で求められる形式と合っているか確認してください
- このリポジトリには会社固有の情報を入れないでください（設定画面から Base に保存されます）
